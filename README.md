# Naman Sahu — Interactive Portfolio

A dark-themed, animated personal portfolio website for Naman Sahu, Data Engineer.

## 🚀 Live Demo
Deploy via GitHub Pages — see setup instructions below.

## ✨ Features
- Animated hero with particle background and custom cursor
- Scroll-reveal animations on all sections
- Interactive skill cards with animated progress bars
- Timeline-style experience section
- Fully responsive design
- Pure HTML/CSS/JS — no frameworks, no build step

## 📁 Structure
```
portfolio/
├── index.html       # Complete portfolio (single file)
└── README.md
```

## 🌐 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `naman-sahu-portfolio`)
2. Push this folder's contents to the `main` branch
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)`
5. Click **Save** — your site will be live at `https://YOUR_USERNAME.github.io/naman-sahu-portfolio/`

## 🛠 Local Development
Simply open `index.html` in your browser — no server needed.
